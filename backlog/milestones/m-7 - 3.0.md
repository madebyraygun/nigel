## Description

End-to-end encrypted sync and sharing: books shared across devices and people (a bookkeeper in a browser) through Nigel Cloud, which never holds a key or a readable byte of the books, and holds only items the operator has chosen to publish. Scheduled deliveries and incoming events work with no device online. Pursued if Nigel gains traction after 2.0.
