## Description

Mac App Store, server/client, invoices, contracts. A new user installs Nigel from the Mac App Store, chooses where the books live, and sends invoices and contracts with no cloud accounts (local delivery) or through Nigel Cloud delivery; the Mac app connects to a headless nigel serve with per-user logins; existing CLI books open in the store app with nothing lost; CLI and server 2.0.0 release from public CI. Integer money (decision-7) and removing the TUI dashboard (decision-8) land here.
